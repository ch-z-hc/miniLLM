Creation order

Files were created strictly in dependency order — each file is runnable and verifiable before the next one begins. Phase 0 (Baseline evaluation) is complete. Phase 1 SFT has started (configs/sft.yaml done, default 4×3090).

01 · 2026-08-30 · Config

configs/eval.yaml

Single source of truth for evaluation. Defines model path and dtype, data paths, generation parameters, batch size, seed and output directory. Every run saves a snapshot to results/*/config_snapshot.json for reproducibility.

  • Model: tmp_models/Qwen/Qwen2___5-1___5B-Instruct, bfloat16
  • Data: data/gsm8k/test.parquet, max_samples: 20 for smoke test
  • Generation: max_new_tokens 512, do_sample false, batch 4
02 · 2026-08-30 · Source

src/verifier.py

Answer extraction and correctness check. Also serves as the reward function foundation for the later GRPO stage.

  • extract_ground_truth — text after ####
  • extract_boxed — last \boxed{...} occurrence
  • extract_final_answer — boxed first, fallback to trailing number
  • normalize_answer / is_correct — strip $,% and commas, tolerant numeric comparison (1e-2)
03 · 2026-08-30 · Source

src/prompts.py

Prompt construction and Chat Template wrapping. Wraps a raw GSM8K question with a \boxed{} instruction and renders it via the tokenizer's Qwen ChatML template, falling back to plain text when unavailable.

  • build_gsm8k_prompt(question)
  • apply_chat_template(tokenizer, prompt)
04 · 2026-08-30 · Source

src/utils.py

Shared utilities for reproducibility and persistence.

  • set_seed — Python / NumPy / Torch / CUDA
  • save_json / save_jsonl — atomic write via .tmp + replace
  • ensure_dir / load_yaml
05 · 2026-08-30 · Script

scripts/eval.py

End-to-end evaluation pipeline. Loads YAML and parquet, tokenizes in batches, runs model.generate, decodes, verifies, computes metrics and writes structured outputs. Includes the left-padding slicing fix (outputs[j, padded_len:]).

  • Input: configs/eval.yaml + data/gsm8k/*.parquet
  • Output: results/eval_baseline/{config_snapshot.json, generations.jsonl, generations.csv, metrics.json}
  • Verified: 20 samples, ~70s, accuracy 0.5 / boxed 0.7
06 · 2026-08-31 · Config

configs/sft.yaml

SFT training config for Qwen2.5-1.5B LoRA. Default for 4×3090 24GB (DDP); compatible with single RTX 4060 8GB by toggling 3 lines. Teaches \boxed{} format on GSM8K.

  • Model: tmp_models/Qwen/Qwen2___5-1___5B-Instruct, bfloat16, max_seq_length 1024
  • LoRA: r 16, alpha 32, dropout 0.05, targets q/k/v/o + gate/up/down
  • Training: per_device 4 × 4 GPU × accum 4 = eff 64 (single eff 16), 2 epochs ≈234 steps, lr 2e-4 cosine, ckpt off on 3090
Next: src/data.py (parquet → ChatML text with ####→\boxed{}). Phases SFT → GRPO → Test-Time Scaling → Adaptive follow config → source → script, each committed with docs/index.html updated. Local progress is tracked in AGENTS.md (not versioned, per .gitignore).

What depends on what

configs/eval.yaml

Read by scripts/eval.py only. No other file imports it.

src/verifier.py

Used by scripts/eval.py and later src/rewards.py (GRPO).

src/prompts.py

Used by scripts/eval.py and later scripts/train_sft.py.

src/utils.py

Used by every script for seeding and saving.

configs/sft.yaml

Read by src/data.py and scripts/train_sft.py. Single-GPU smoke on 4060, DDP on 4×3090 via accelerate launch.

How to run

python scripts/eval.py --config configs/eval.yaml  ·  python scripts/eval.py --max_samples 100
accelerate launch --multi_gpu --num_processes 4 scripts/train_sft.py --config configs/sft.yaml  ·  single-GPU: python scripts/train_sft.py (toggle per_device1/accum16/ckpt on)
