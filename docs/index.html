scripts/eval.py

端到端评测管线。读取 YAML 与 parquet，分批分词，执行 model.generate，解码后用 verifier 判分并统计指标、落盘结构化结果。已修复左填充切片问题（outputs[j, padded_len:]）。

06 · 2026-08-31 · 配置

configs/sft.yaml

Qwen2.5-1.5B LoRA 的 SFT 训练配置。默认适配 4×3090 24GB（DDP），改 3 行即可回退到单卡 RTX 4060 8GB。在 GSM8K 上教会 \boxed{} 推理格式。

  • 模型：tmp_models/Qwen/Qwen2___5-1___5B-Instruct，bfloat16，max_seq_length 1024
  • LoRA：r 16, alpha 32, dropout 0.05，目标 q/k/v/o + gate/up/down
  • 训练：per_device 4 × 4 卡 × accum 4 = eff 64（单卡 eff 16），2 epoch ≈234 步，lr 2e-4 cosine，3090 下 ckpt off
07 · 2026-08-31 · 源码

src/data.py

GSM8K parquet → ChatML text 的 SFT 数据管线。处理 ####→\boxed{}、清理 <<...>> 计算标记，经 Qwen chat_template 拼接为可直接喂给 SFTTrainer 的 text 列。

  • format_assistant_answer — 推理清理 + 追加 \boxed{GT}
  • build_sft_text — 单条 question+answer → ChatML 文本（优先 chat_template，fallback 纯文本）
  • load_sft_datasets — 按 configs/sft.yaml 产出 HF Dataset：7473 train / 200 eval，最长 455 < 1024
08 · 2026-09-01 · 脚本

scripts/train_sft.py

Phase 1 的 LoRA-SFT 训练主脚本：PEFT + transformers.Trainer（本机无 trl，故不依赖）。核心是 prompt 掩码——按 <|im_start|>assistant 切分，prompt 段 label 置 -100，CrossEntropy 只算答案段。

  • PromptMaskedCollator — 训练 right padding，input_ids 补 pad、labels 补 -100
  • --preset 4060 — 单卡 8G 回退：per_device 1 × accum 16 + gradient_checkpointing；--smoke 小数据少步数验证管线
  • 落盘 config_snapshot.json / training_log.jsonl / metrics.json，适配器存 outputs/（约 74 MB）
  • 已验证：4060 冒烟通过，可训练参数 18.5M（1.18%），掩码自检 prompt 98 tok / 监督 98 tok，eval_loss 0.58
下一步：src/rewards.py（correctness + format 可验证奖励，进入 Phase 2 GRPO）。后续 GRPO → Test-Time Scaling → Adaptive 均按 配置 → 源码 → 脚本 顺序推进，每完成一个文件即提交并同步更新本页；本地进度见 AGENTS.md（按 .gitignore 不入库）。

谁依赖谁

configs/eval.yaml

仅被 scripts/eval.py 读取。

src/verifier.py

被 scripts/eval.py 与后续 src/rewards.py（GRPO）使用。

src/prompts.py

被 scripts/eval.py 与后续 scripts/train_sft.py 使用。

src/utils.py

所有脚本共用的种子与落盘工具。

configs/sft.yaml

被 src/data.py 与 scripts/train_sft.py 读取。4060 单卡可冒烟，4×3090 通过 accelerate launch 做 DDP。

src/data.py

被 scripts/train_sft.py 调用，产出含 text 列的 HF Dataset。复用 src/prompts / src/verifier 处理格式。

scripts/train_sft.py

汇合 configs/sft.yaml + src/data.py + src/utils.py，产出 LoRA 适配器供 scripts/eval.py 复评，与 Phase 0 基线对比。

怎么跑

python scripts/eval.py --config configs/eval.yaml  ·  python scripts/eval.py --max_samples 100
accelerate launch --multi_gpu --num_processes 4 scripts/train_sft.py --config configs/sft.yaml  ·  单卡：python scripts/train_sft.py --preset 4060  ·  冒烟：python scripts/train_sft.py --smoke --preset 4060
