02 · 2026-08-30 · 源码

src/verifier.py

答案抽取与正误判定，同时作为后续 GRPO 阶段奖励函数的基础。

  • extract_ground_truth — 抽取 #### 后的真值
  • extract_boxed — 抽取最后一次出现的 \boxed{...}
  • extract_final_answer — 优先 boxed，失败回退到末尾数字
  • normalize_answer / is_correct — 去除 $,% 与逗号，容差 1e-2 的数值比较

05 · 2026-08-30 · 脚本

scripts/eval.py

端到端评测管线。读取 YAML 与 parquet，分批分词，执行 model.generate，解码后用 verifier 判分并统计指标、落盘结构化结果。已修复左填充切片问题（outputs[j, padded_len:]）。

  • 输入：configs/eval.yaml + data/gsm8k/*.parquet
  • 输出：results/eval_baseline/{config_snapshot.json, generations.jsonl, generations.csv, metrics.json}
  • 已验证：20 条约 70 秒，accuracy 0.5 / boxed 0.7
06 · 2026-08-31 · 配置

configs/sft.yaml

Qwen2.5-1.5B LoRA 的 SFT 训练配置。默认适配 4×3090 24GB（DDP），改 3 行即可回退到单卡 RTX 4060 8GB。在 GSM8K 上教会 \boxed{} 推理格式。

  • 模型：tmp_models/Qwen/Qwen2___5-1___5B-Instruct，bfloat16，max_seq_length 1024
  • LoRA：r 16, alpha 32, dropout 0.05，目标 q/k/v/o + gate/up/down
  • 训练：per_device 4 × 4 卡 × accum 4 = eff 64（单卡 eff 16），2 epoch ≈234 步，lr 2e-4 cosine，3090 下 ckpt off
下一步：src/data.py（parquet → ChatML text，处理 ####→\boxed{}）。后续阶段 SFT → GRPO → Test-Time Scaling → Adaptive 均按 配置 → 源码 → 脚本 顺序推进，每完成一个文件即提交并同步更新本页；本地进度见 AGENTS.md（按 .gitignore 不入库）。

谁依赖谁

configs/eval.yaml

仅被 scripts/eval.py 读取。

src/verifier.py

被 scripts/eval.py 与后续 src/rewards.py（GRPO）使用。

src/prompts.py

被 scripts/eval.py 与后续 scripts/train_sft.py 使用。

src/utils.py

所有脚本共用的种子与落盘工具。

configs/sft.yaml

被 src/data.py 与 scripts/train_sft.py 读取。4060 单卡可冒烟，4×3090 通过 accelerate launch 做 DDP。

怎么跑

python scripts/eval.py --config configs/eval.yaml  ·  python scripts/eval.py --max_samples 100
accelerate launch --multi_gpu --num_processes 4 scripts/train_sft.py --config configs/sft.yaml  ·  单卡：python scripts/train_sft.py（改 per_device1/accum16/ckpt on 即可）

硬件与可复现说明见 README.md。
